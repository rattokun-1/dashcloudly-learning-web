# 個人のPCで安全確認する

Windowsでは `tools/security-check.cmd` をダブルクリックします。Node.js 22以降が必要です。このPCでは既存のCodex付属Node.jsも利用できます。PowerShellの実行ポリシー変更や管理者権限は不要です。

macOS / Linux、またはターミナルからは、リポジトリ直下で次を実行します。

```sh
node tools/security-check.mjs
# npmが利用できる場合
npm run security:check
```

## 調べること

- Git追跡対象と、無視設定に入っていない未追跡ファイルの秘密情報・実教材パターン。Gitなしの配布物ではフォルダー内を走査
- JavaScriptの構文と、HTMLを含む生成入力・文字数超過の拒否
- リポジトリの単体テスト
- 外部依存パッケージの宣言数（脆弱性データベースの照合ではありません）

結果は `security-reports/security-check-日時.json` に保存します。FAILなら終了コード1、検査通過なら0です。レポートはGit対象外で、自動アップロードしません。検出時はファイル名と理由だけを記録し、秘密情報の本文は保存しません。レポートにも非公開ファイル名が含まれる可能性があるため、そのまま公開しないでください。

## 範囲と限界

これはオフラインの簡易確認です。PASS_LIMITEDは「実施した項目が通った」という意味で、脆弱性が存在しない保証ではありません。サーバーへの攻撃、ログイン、メール送信、データ変更、依存パッケージのインストールはしません。検査本体は外部へ通信しませんが、**単体テストは対象リポジトリのコードを実行します**。信頼できるこのリポジトリのコピーだけで実行してください。

無視ファイル、Git履歴、未知の秘密情報形式、画像に写った情報、実際の認証・Firestoreルール・公開サーバー設定・ブラウザー動作・依存パッケージの最新CVEまでは保証できません。外部パッケージを追加した場合は別途アドバイザリ照合も必要です。4MiBを超えるテキストやリンクは通過扱いにせず、手動確認を求めます。

UIの動作確認は `tests/keyboard-study.browser.cjs` と `tests/compact-header.browser.cjs` を生成デモで実行します。設定は[キーボードガイド](KEYBOARD-CHECK.md)を参照してください。脆弱性の疑いは公開Issueに秘密情報を書かず、[非公開の報告手順](../SECURITY.md)を使ってください。

対象はPR #13のキーボード処理・フォーカス移動・境界テストです。認証や権限を緩める変更、外部への送信、ユーザー入力によるセレクター生成、動的コード実行は追加していません。移動先はコード内で固定し、別操作・画面切替・ダイアログ・inertを確認します。入力上限のテストは既存の拒否規則を維持しています。この差分から新たな脆弱性は確認されていません。サービス全体の安全性やサーバー側の認可を確認した結論ではありません。
