# 導入ガイド

## UIデモ

`npm start` で起動します。教材やFirebaseの設定は不要です。
学習それぞれの記録は、この公開版専用の保存キーを使います。

## Localモード

`shared/config.local.json` の `mode` を `local` にし、[教材を用意](DATA.md)します。
学習記録はブラウザー内で扱い、アカウント作成・クラウド同期は行いません。

## Connectedモード

これは既存の認証・同期基盤を持つ運用者向けです。初期設定のまま有効にしないでください。

必要な設定は次のとおりです。

| 設定 | 内容 |
| --- | --- |
| `mode` | `connected` |
| `firebase` | ご自身のFirebase Web設定。サービスアカウント秘密鍵を渡さない |
| `hubUrl` | ご自身の共通学習IDのHTTPS URL |
| `datasetUrl` | 学習ページから見た教材JSONのURL |
| `adminEmails` / `adminUids` | 画面上の管理者判定用。サーバーの認可を代替しない |

Firebase SDKはConnectedモードを選んだ場合だけ読み込みます。
認証用ドメイン、CORS、コールバック先、同意の確認、学校やランキングのAPIも運用環境で設定する必要があります。
共通学習ID・メール・パスキーのサーバー実装は別システムです。この公開リポジトリだけでは稼働しません。

学習画面の `firestore.rules.example` は検討用のひな形です。独自の管理者判定・同意版・権限・APIの構成に合わせてレビューしてから適用してください。
本番のプロジェクトID、管理者個人のメール、ネットワーク許可リストは配布していません。

## 静的配信

公開プログラムはHTML・CSS・JavaScriptで構成され、ビルドは不要です。
任意の静的配信環境で使えます。PWA機能にはHTTPSまたはlocalhostが必要です。
管理者画面のネットワーク制限、認可、教材の配信範囲は、ご自身のサーバー側で設定してください。
