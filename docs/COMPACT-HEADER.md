# 小型メニューバーの確認

ページ先頭では通常の上部バーを表示し、スクロール中は中央の小型バーへ切り替えます。学習中は進捗と中断を直接操作でき、小型バーの中央ボタンで通常サイズへ展開できます。Escape、ホイール、タッチ移動で再び折り畳みます。プロフィール写真が未設定の場合は人物アイコンを表示します。

## 自動確認（任意）

PlaywrightとChromeを利用できる環境で、生成デモのまま実行します。認証基盤や実教材は不要です。

```sh
PORT=3013 npm start
# 別ターミナル
node tests/compact-header.browser.cjs
```

Windows PowerShellでは起動前に `$env:PORT='3013'` を設定します。Playwrightを別の場所に導入している場合は `PLAYWRIGHT_MODULE`、Chromeを指定する場合は `CHROME_EXECUTABLE`、別ポートの場合は `STUDY_URL` に学習画面のURLを指定します。通常の `npm test` にブラウザー依存は追加しません。

390×844 / 1280×844のChromeで、以下を検証します。

- 先頭の通常表示、スクロール時の縮小、アニメーション軽減
- タップ展開時のスクロール位置保持とフォーカス可能状態
- 学習中の進捗と中断、進捗値の同期
- 4回続けて展開・Escapeを操作しても安定すること
- 横溢れ・JavaScriptエラーがないこと

スクロール検証には、教材を含まない高さだけの要素をデモのホームへ一時追加します。写真・個人情報・実教材・本番設定は検証記録へ含めません。
