## 再現手順

1. [ガイドの準備](../KEYBOARD-CHECK.md#1-準備)に従って新規の生成デモを起動し、Tab・Enterで学習を開始する。
2. Tabで任意の選択肢を選び、Enterで回答する。正解・不正解は問わない。
3. 解答と「次の問題へ」が表示されるまで待つ。
4. Tabを繰り返して、表示中の「中断」ボタンにフォーカス枠を移す。
5. 問題番号を記録してからEnterを1回押す。

## 期待する動作

中断確認ダイアログが開きます。問題番号は変化せず、操作対象はダイアログへ移ります。Escapeで取り消した場合も、同じ問題・同じ回答状態を保ちます。

## 実際の動作

中断確認は開かず、問題番号が第1問から第2問へ増えました。画面は学習中のままで、「中断」ボタンにフォーカスが残りました。1回のEnterが、フォーカスしている「中断」ではなく「次の問題へ」として処理されています。

対照確認として、未回答で「次の問題へ」が非表示の状態では、同じTab→「中断」→Enterで確認ダイアログが開きました。確認画面はAPIで取り消しており、実キーEscapeの動作は今回の確認に含めません。

## 切り分けと確認範囲
