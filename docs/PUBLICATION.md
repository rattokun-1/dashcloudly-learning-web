# 公開ポリシー

このリポジトリは、プログラム専用の配布先です。
教材を含む運用リポジトリから `.git` をコピーせず、新しいGit履歴で作成しています。

## 公開するもの

- 学習のHTML・CSS・JavaScript
- 教材を外部から読むロジックと、生成式によるUIプレースホルダー
- 個別設定・権限ルールのひな形
- 設定手順、テスト、公開内容を検査するCI
- 教材・利用者情報を含まないUI画像

## 公開しないもの

- 実際の単語、訳語、発音辞書、教材ファイル
- 個人のプロフィール・回答履歴・学校の名簿
- 本番の管理者情報、秘密鍵、環境設定、ネットワーク許可リスト
- データベース、ログ、バックアップ、教材を含む旧Git履歴

## PRとブランチ

公開用PRでも、元の教材入りブランチをpushしないでください。
差分だけ教材を削除しても、以前のコミットに残るため公開用の履歴として使えません。

レビュー前に `npm test` と `npm run audit:public` を実行し、Gitで追跡されるファイルを確認します。
CIは自動検出を補助するものです。画像、自由形式の文書、別名にしたデータなども人が確認してください。
