# コードを編集せずに設定する

最初に `npm run configure` を実行します。設定と12個の生成項目を作成します。既存ファイルは上書きしません。

## サイト・学習設定

`shared/config.local.json` を編集し、ページを再読み込みしてください。

| 設定 | 内容 |
| --- | --- |
| `site.name` | サイト名。60文字以内。ページタイトル・学習ヘッダー・PWA名に反映 |
| `site.description` | 説明。200文字以内。トップページとメタ情報に反映 |
| `site.icon` | `shared/` を基準とする画像パス。同じサイトのSVG・PNG・WebP・ICO |
| `learning.setSize` | 1セットの項目数。6〜500 |
| `learning.questionCount` | 初期の出題数。1〜500。出題可能な項目数に調整 |
| `learning.mode` | 1: 項目→解答の6択、2: 解答→項目の6択、3: 解答→項目の入力 |
| `learning.autoVoice` | 自動読み上げの初期値。true / false |
| `speechLanguage` | 読み上げ言語。例: ja-JP |
| `datasetUrl` | 学習ページを基準とする教材ファイル。初期値は data/content.json |
| `mode` | demo / local / connected。生成した教材で学ぶ場合はlocal |

アイコンは自分の画像に置き換えてください。例えば `shared/my-icon.png` を置き、`site.icon` を `my-icon.png` にします。正方形で512px以上のPNGを推奨します。すでにインストールしたPWAの名前・アイコンはブラウザーの更新タイミングに依存し、再インストールが必要な場合があります。

本人のプロフィール画像や学校ロゴはサイトアイコンと別です。読み上げの設定を画面で変更した場合はその端末の選択を優先します。初期の出題数・モードも学習中に変更できます。

## 項目を追加する

`apps/study/data/content.json` の `items` に追記します。次の形式を使います。

```json
{
  "id": 13,
  "term": "追加する項目",
  "answer": "その解答",
  "isNew": false
}
```

IDは1から始まる連番で、既存のIDを変更せず末尾に追加してください。`isNew` は省略するとfalseになります。最低6項目が必要です。JSONでは末尾に余分なカンマを付けられません。詳細は [教材の仕様](DATA.md) を確認してください。

設定と教材はGit管理対象外で、配布パッケージにも含めません。ブラウザーから読み込む設定には秘密鍵・管理者パスワード等を保存しないでください。教材を配信する権利は利用者が確認してください。

設定に誤りがあれば起動画面でエラーを表示します。公開配信では設定・教材を個別に配置してください。PWAでオフライン利用する際は、配信側のキャッシュ設定が許可している必要があります。
