# 教材とプログラムを分ける

公開リポジトリには、実際の単語・訳語・発音辞書を置きません。
画面確認用の項目は `shared/data-loader.mjs` が実行時に生成します。

## 端末内で教材を使う

1. `shared/config.example.json` を `shared/config.local.json` にコピーします。
2. `mode` を `local` にします。
3. 学習画面の `apps/study/data/content.json` をご自身で用意します。

これらの設定ファイルと `data/` はGitの管理対象外です。

## JSONの仕様

| フィールド | 形式 | 条件 |
| --- | --- | --- |
| `schemaVersion` | 数値 | `1` |
| `items` | 配列 | 6〜10,000項目。6択の選択肢を作るため最低6項目 |
| 各項目 | `{id, term, answer, isNew}` または従来の4要素配列 | 名前付きの項目形式を推奨 |
| `id` | 数値 | 1から始まる連番。配列の順序と一致 |
| `term` / `answer` | 文字列 | 空欄不可。各500文字以内。HTMLを含めない |
| `phonetics` | オブジェクト・省略可 | 語句をキーとする発音表記。各100文字以内。HTMLを含めない |

完成した教材の見本は、このリポジトリへコミットしません。
形式に問題がある場合は学習画面の読み込みを停止し、確認を促します。

## 取り扱い

- 利用・配信できることを確認した教材だけを使ってください。
- 公開サイトへ配信した教材は、ブラウザーから取得できます。Gitの非公開化だけでWeb上の配信が非公開になるわけではありません。
- スクリーンショット、テスト用ファイル、PR本文にも実教材を転載しないでください。
- 教材変更時はIDと既存の進捗の対応を確認してください。IDを別の語句へ使い回すと、端末内の過去の記録と対応しなくなります。
